Este é um kit de ferramentas em Python feito para rodar direto no terminal. Ele possui módulos de segurança, redes, criptografia e automação.

## 📋 Pré-requisitos

Antes de começar, você precisa ter o **Python 3** instalado no seu computador.

## 🚀 Como Instalar e Rodar

Escolha as instruções baseadas no seu sistema operacional:

### 🪟 No Windows (Command Prompt ou PowerShell)

1. **Baixe o projeto** ou clone o repositório:
   ```cmd
   git clone https://github.com
   cd SKID-TOOL-KIT
   ```

2. **Instale as dependências** necessárias:
   ```cmd
   pip install -r requirements.txt
   ```

3. **Inicie o programa**:
   ```cmd
   python main.py
   ```

---

### 🐧 No Linux (Ubuntu/Debian e derivados)

1. **Abra o terminal** e baixe o projeto:
   ```bash
   git clone https://github.com
   cd SKID-TOOL-KIT
   ```

2. **Instale as dependências**:
   ```bash
   pip3 install -r requirements.txt
   ```

3. **Inicie o programa**:
   ```bash
   python3 main.py
   ```

## 📂 Estrutura do Projeto

* `main.py`: Arquivo principal que abre o menu do terminal.
* `modules/`: Pasta com as ferramentas (Bruteforce, Criptografia, Redes, Malware, etc).
* `utils/`: Funções de ajuda para exibição e telas.
